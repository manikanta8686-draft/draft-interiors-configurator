# Upholstery Runtime Texture Sources

All source assets listed below are published under the Creative Commons CC0 1.0 licence and may be used commercially. Runtime copies were resized to 1024 x 1024, JPEG-compressed, and their base-colour maps were neutralized so the configurator's existing colour swatches can tint them consistently. Normal maps use the OpenGL convention.

| Configurator upholstery | Source asset | Source page | Runtime folder |
| --- | --- | --- | --- |
| Performance Polyester / Microfiber | ambientCG Fabric 010 | https://ambientcg.com/view?id=Fabric010 | `performance/` |
| Linen & Jute Blend | ambientCG Fabric 019 | https://ambientcg.com/view?id=Fabric019 | `linen-jute/` |
| Polyester Velvet | Poly Haven Velour Velvet | https://polyhaven.com/a/velour_velvet | `velvet/` |
| Suede | Poly Haven Scuba Suede | https://polyhaven.com/a/scuba_suede | `suede/` |
| Cotton Chenille | ambientCG Fabric 031 | https://ambientcg.com/view?id=Fabric031 | `chenille/` |
| Leatherette / PU | ambientCG Leather 037 | https://ambientcg.com/view?id=Leather037 | `leatherette/` |

Each runtime folder contains:

- `basecolor-neutral.jpg`
- `normal-gl.jpg`
- `roughness.jpg`
